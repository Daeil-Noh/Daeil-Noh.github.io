연구 분야

양자 알고리즘과 딥러닝을 결합한 하이브리드 모델을 핵심으로, 통신·비전·제조 분야의 응용 연구를 함께 수행합니다.

양자 컴퓨팅Quantum Computing

양자 컴퓨터는 중첩과 얽힘을 이용해 고전 컴퓨터와 다른 방식으로 계산합니다. 연구실은 이 특성을 실제 공학 문제의 최적화에 활용하는 방법을 연구합니다.

  • 양자 어닐링 기반 조합 최적화
  • 무선 네트워크 자원 할당 문제의 양자 최적화 모델링
  • 양자 회로 설계와 시뮬레이션
관련 논문: Embedding-aware noise modeling of quantum annealing · Quantum-Annealing-Based Sum Rate Maximization for Multi-UAV-Aided Wireless Networks

양자 머신러닝Quantum Machine Learning

양자 회로를 학습 가능한 모델로 사용하는 양자 머신러닝은 적은 파라미터로 복잡한 표현을 학습할 가능성이 있습니다. 연구실은 고전 딥러닝 구조와 양자 회로를 결합한 하이브리드 모델을 연구합니다.

  • 변분 양자 회로(VQC) 기반 분류 모델
  • 하이브리드 양자-고전 신경망 구조 설계
  • 시계열·이미지 데이터 분류 응용
관련 논문: Hybrid Quantum ResNet for Time Series Classification

컴퓨터 비전Computer Vision

영상에서 의미 있는 정보를 찾아내는 컴퓨터 비전 기술을 의료와 산업 현장에 적용합니다.

  • Transformer 기반 영상 분류·분할
  • 의료 영상 질환 검출
  • 객체 검출과 영상 분할
관련 논문: GlaucoFormer

무선 통신Wireless Communication

무선 신호와 네트워크 문제에 딥러닝을 적용해 기존 신호처리 방법의 한계를 넘는 것을 목표로 합니다.

  • 딥러닝 기반 자동 변조 분류(AMC)
  • RF 신호 기반 UAV 탐지·분류
  • 다중 UAV 무선 네트워크 최적화
관련 논문: VT-MCNet · Signal Preprocessing Technique With Noise-Tolerant for RF-Based UAV Signal Classification

스마트 팩토리Smart Factory

제조 데이터와 AI를 결합해 생산 현장의 품질과 효율을 높이는 응용 연구를 진행합니다.

  • 영상 기반 제품 품질 검사
  • 센서 데이터 이상 탐지
  • 공정 데이터 분석과 최적화
